# Dice Roller

**Your game, your rules, your roll.**

Dice Roller is a collection of open-source JavaScript and TypeScript tools for rolling dice in tabletop role-playing games.

At its heart is **RPG Dice Roller**, a flexible and powerful dice rolling engine that supports everything from simple dice rolls to complex expressions, modifiers, and custom game mechanics.

Whether you're building a virtual tabletop, a character sheet, a game companion, or something entirely different, Dice Roller provides the tools to bring dice rolling into your application.

### What can it do?

- 🎲 **Flexible dice notation** — Roll standard, percentile, Fudge, and custom dice.
- ⚙️ **Powerful modifiers** — Exploding dice, rerolls, keep/drop, success counting, and more.
- 🧮 **Complex expressions** — Combine dice rolls with mathematical expressions and functions.
- 🧩 **Extensible** — Customise dice behaviour, modifiers, random number generation, and result presentation.
- 🌐 **Framework integrations** — Use the core library directly or integrate it with Vue, Markdown, and documentation frameworks.

## 🚀 Getting started

Start off by checking out the installation instructions, dice notation, API references, and examples in the [**documentation**](https://dice-roller.github.io/documentation/).

## 📦 Our projects

Dice Roller is more than just a dice rolling library. The organisation maintains a collection of tools and integrations built around the core engine.

| Project                                                                         | Description                                                                       |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 🎲 [RPG Dice Roller](https://github.com/dice-roller/rpg-dice-roller)            | The core JavaScript dice rolling engine.                                          |
| 🖥️ [CLI](https://github.com/dice-roller/cli)                                    | Roll dice directly from your terminal.                                            |
| 🟢 [Vue Components](https://github.com/dice-roller/vue)                         | Ready-to-use Vue components and composables for building dice rolling interfaces. |
| 📝 [Markdown-it Plugin](https://github.com/dice-roller/markdown-it-dice-roller) | Add dice rolling functionality to Markdown documents.                             |
| 📘 [VuePress Plugin](https://github.com/dice-roller/vuepress-plugin)            | Integrate interactive dice rolling into VuePress sites.                           |
| 📗 [VitePress Plugin](https://github.com/dice-roller/vitepress-plugin)          | Add dice rolling functionality to VitePress documentation.                        |
| 📚 [Documentation](https://github.com/dice-roller/documentation)                | The documentation website, notation reference, and guides.                        |
